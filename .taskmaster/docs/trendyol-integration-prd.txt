# Overview  
Integrate Trendyol marketplace into the existing shipping and order sync platform to enable users to sync orders from Trendyol and manage their fulfillment through the unified dashboard. This integration follows a minimal-impact rollout approach with feature flags to ensure zero disruption to existing marketplace integrations (Veeqo, Shippo, etc.).

# Core Features  
- **Order Synchronization**: Fetch and sync orders from Trendyol marketplace using their REST API
- **Order Management**: Display Trendyol orders in the unified dashboard alongside existing marketplace orders
- **Address Mapping**: Convert Trendyol shipping addresses to standardized format for future shipping integrations
- **Feature Flag Control**: Enable/disable Trendyol functionality without affecting existing features
- **Incremental Sync**: Fetch only new/updated orders since last sync to optimize performance

# User Experience  
- **Merchants**: Trendyol sellers who want to manage their orders through a unified platform
- **Key User Flows**:
  - Configure Trendyol API credentials in settings
  - View Trendyol orders in the main orders dashboard
  - Filter orders by marketplace (including Trendyol)
  - See Trendyol order details and status
- **UI/UX Considerations**:
  - Trendyol orders appear seamlessly alongside existing marketplace orders
  - Distinctive Trendyol branding/icons for easy identification
  - No new pages or complex UI changes required

# Technical Architecture  
- **System Components**:
  - Trendyol REST API client with authentication
  - Order/OrderItem mappers for data transformation
  - Background job processor for periodic sync
  - Feature flag system for controlled rollout
  
- **Data Models**:
  - Reuse existing Order, OrderItem, ShippingAddress models
  - Store Trendyol-specific IDs in existing marketplaceOrderId field
  - Map Trendyol status to existing OrderStatus enum
  
- **APIs and Integrations**:
  - Trendyol Seller API for order fetching
  - Existing sync pipeline for order processing
  - Redis cache for lastSyncAt tracking
  
- **Infrastructure Requirements**:
  - No new external dependencies
  - Reuse existing Bull queue for background jobs
  - Feature flag environment variables

# Risks and Mitigations  
- **Technical Challenges**:
  - Risk: Trendyol API changes or rate limits
  - Mitigation: Robust error handling and API versioning
  
- **Data Integrity**:
  - Risk: Mapping errors causing data corruption
  - Mitigation: Comprehensive unit tests and validation
  
- **Feature Flag Complexity**:
  - Risk: Flag logic becoming complex and error-prone
  - Mitigation: Simple boolean flags with clear boundaries
  
- **Shipping Integration Limitation**:
  - Risk: Users expecting immediate shipping label generation
  - Mitigation: Clear documentation that shipping integration comes later with Turkish cargo companies

# Appendix  
- **Research Findings**: Trendyol uses domestic shipping only, requiring future integration with Turkish cargo companies (Trendyol Express, Aras Kargo, etc.)
- **Technical Specifications**: 
  - Trendyol API uses OAuth-style signed requests
  - Orders have unique trendyolOrderNumber field
  - Status mapping required for order lifecycle management
  - No immediate shipping label generation (domestic-only marketplace)
- **Environment Variables**:
  - MARKETPLACE_TRENDYOL (boolean, default false)
  - TRENDYOL_SUPPLIER_ID
  - TRENDYOL_API_KEY  
  - TRENDYOL_API_SECRET
  - ALLOW_TRENDYOL_USERS (user ID list for gradual rollout)

# Product Requirements Document: Trendyol Marketplace Integration

## Executive Summary
Integrate Trendyol marketplace into the existing multi-marketplace shipping and order management platform using a minimal-impact, feature-flagged approach. This integration will enable merchants to sync orders from Trendyol and manage them through the unified dashboard, with future support for Turkish domestic shipping providers.

## Functional Requirements

### F1: Order Synchronization
- Fetch orders from Trendyol Seller API using supplier credentials
- Map Trendyol order data to existing Order/OrderItem models
- Store Trendyol order numbers in marketplaceOrderId field
- Implement incremental sync based on updatedAt timestamps
- Support both manual and scheduled sync operations

### F2: Data Mapping & Transformation
- Convert Trendyol order status to existing OrderStatus enum
- Map Trendyol shipping addresses to ShippingAddress model
- Transform product data to OrderItem format
- Handle Trendyol-specific fields (supplier ID, domestic shipping flags)
- Preserve original Trendyol data in raw JSON fields

### F3: UI Integration
- Display Trendyol orders in existing orders dashboard
- Add Trendyol to marketplace filter dropdown
- Show Trendyol badge/icon for easy identification
- Ensure order details page works with Trendyol orders
- No new pages or major UI changes required

### F4: Background Processing
- Extend existing Bull queue with Trendyol sync jobs
- Schedule periodic sync operations (configurable interval)
- Implement proper error handling and retry logic
- Add job monitoring and status tracking
- Cache lastSyncAt timestamp in Redis

### F5: Feature Flag Control
- MARKETPLACE_TRENDYOL environment variable (default false)
- Wrap all Trendyol functionality behind feature flag
- Support gradual user rollout via ALLOW_TRENDYOL_USERS
- Ensure zero impact when flag is disabled
- Provide easy rollback mechanism

## Technical Requirements

### T1: Authentication & API Client
- Implement Trendyol REST API client using existing HTTP library
- Support OAuth-style signed request authentication
- Handle API rate limiting and error responses
- Sandbox/production environment switching
- Comprehensive error logging and monitoring

### T2: Data Architecture
- Reuse existing database schema (no new tables)
- Utilize existing Order, OrderItem, ShippingAddress models
- Store Trendyol-specific metadata in existing JSON fields
- Maintain referential integrity and constraints
- Support future shipping integration data requirements

### T3: Sync Architecture
- Leverage existing sync pipeline and patterns
- Implement incremental sync with cursor-based pagination
- Support both full and delta sync operations
- Handle duplicate detection and order updates
- Preserve sync history and audit trail

### T4: Shipping Integration Preparation
- Map Trendyol addresses to standard shipping format
- Validate address data completeness
- Prepare for future Turkish cargo company integrations
- Document shipping limitations (domestic only)
- Maintain compatibility with existing shipping providers
